Política de Privacidade

CRM PoC — última atualização: outubro de 2026

Esta página descreve o tratamento de dados de uma prova de conceito (PoC) acadêmica de CRM automotivo, desenvolvida como parte de um estudo sobre desenvolvimento de software conduzido por IA. Não é um produto comercial da Webmotors nem reflete a política de privacidade oficial da empresa — é a política deste projeto de demonstração específico, mantido por seu autor.

O que é este serviço

O CRM PoC é um sistema interno de demonstração usado para registrar e responder, em nome de uma revenda de veículos fictícia, conversas de clientes recebidas por WhatsApp, e-mail e outros canais de origem de leads (portais automotivos, por exemplo). O projeto integra oficialmente com a API do WhatsApp Business (Meta Cloud API) para registrar essas conversas automaticamente.

Quais dados são coletados

  • Nome e número de telefone do cliente que entra em contato;
  • Conteúdo das mensagens trocadas entre o cliente e a equipe de vendas pelo WhatsApp;
  • Veículo de interesse e dados do atendimento comercial (etapa da negociação, vendedor responsável, resultado);
  • Metadados técnicos da integração com a Meta (identificadores de mensagem, status de entrega/leitura).

Finalidade

Os dados são usados exclusivamente para possibilitar o atendimento comercial do cliente (responder suas mensagens, acompanhar o andamento da negociação) e, de forma agregada e sem identificação pessoal, para medir indicadores de atendimento no âmbito do projeto de pesquisa (ex.: tempo médio de primeira resposta).

Com quem os dados são compartilhados

Os dados não são vendidos nem compartilhados com terceiros. São acessados apenas pela equipe de atendimento da revenda (vendedores e gestores) autorizada no próprio sistema, e pela Meta Platforms, Inc., na qualidade de provedora da API de mensageria do WhatsApp usada para o envio e recebimento das mensagens.

Retenção

O conteúdo bruto recebido pela integração com a Meta (payload do webhook) é retido por até 7 dias, apenas para fins de reprocessamento em caso de falha técnica, e depois descartado. Os dados estruturados da conversa (mensagens, status do atendimento) são retidos enquanto o atendimento permanecer relevante para o estudo, podendo ser anonimizados ou removidos mediante solicitação.
